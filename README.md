# Seating Chart

A classroom seating chart that keeps talkers apart. Works on a phone, laptop, or projector, and works offline.

## Use it
Open `index.html` in a browser (Chrome, Safari, Edge). On an iPhone, open the web link in Safari, tap **Share**, then **Add to Home Screen**.

1. **Students** tab: tap **Paste names** and paste your class list (one name per line).
2. Tap **Talker** on each student who talks a lot. Talkers are never placed next to another talker (side, front/back, diagonal, or at the same table).
3. Optional tags: **Front** (needs a front seat), **Quiet** (kept away from talkers), **Keep apart…** (never sit together with chosen classmates), **Lock seat** (Auto-arrange leaves them alone). You can also add pairs under **Never sit together**.
4. **Chart** tab: tap **Auto-arrange**. Tap a student, then another seat to swap (or drag on a computer). Seats that would cause a problem turn red before you tap; the **Conflicts** list shows anything that needs fixing.
5. **Print / Save** prints names only (front of room labeled). **Big view** fills the screen for the projector and hides tags.
6. **Setup** tab: desk layout (tables of 4 or 6, pairs, rows), number of seats, classes, **Export/Import backup**, and **Start fresh**.

## Privacy
Student names and tags are saved only in this browser on this device (localStorage). The app makes no network requests (enforced by a Content Security Policy). Use **Export backup** to move your data to another device.
